PIDEMS and explainability methods

LIME and SHAP are not meaningful for models that only output hard class labels, because both methods rely on observing how the model’s output changes when the input is perturbed. If the model only returns 0/1 labels, small changes in the input usually do not alter the prediction, leaving nothing for these methods to approximate. Hard labels also discard valuable information about the model’s confidence: a prediction made with 99% certainty looks the same as one made with 51% certainty when only the final class is shown. As a result, the surrogate models that LIME and SHAP build cannot capture meaningful feature contributions, and the resulting explanations are unstable or misleading. In practice, these explanation methods are useful only when the model provides continuous outputs, such as probabilities or decision scores, rather than just discrete classes, because that continuous signal is what allows them to explain how features influence predictions.
